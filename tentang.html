Tentang Project

Latar belakang, cakupan penelitian, metode pengolahan data, serta batasan informasi pada WebGIS Rumah Makan Malam.

◉

Tujuan project

Project ini bertujuan membantu masyarakat, mahasiswa, pekerja shift malam, dan pendatang menemukan rumah makan yang masih beroperasi setelah pukul 23.00 WITA. Informasi disajikan secara spasial agar pengguna dapat melihat sebaran lokasi dan memilih tempat makan terdekat.

⊞

Cakupan penelitian

Penelitian mencakup empat wilayah di Provinsi Kalimantan Selatan:

Banjarmasin Kota Banjarmasin
Banjarbaru Kota Banjarbaru
Martapura Kabupaten Banjar
⚙

Metode dan alat

QGIS direncanakan sebagai alat utama untuk pengolahan data spasial. Website ini merupakan antarmuka yang dikembangkan untuk menampilkan data spasial tersebut, dan bukan merupakan sistem GIS yang lengkap.

1

Pengumpulan data

Pengumpulan data rumah makan dilakukan melalui web scraping menggunakan Python dari Google Maps, meliputi nama, alamat, jam operasional, dan informasi kisaran harga apabila tersedia.

2

Pengolahan spasial di QGIS

Digitalisasi titik lokasi, validasi koordinat, dan penyusunan atribut sebelum diekspor.

3

Ekspor GeoJSON

Hasil olahan diekspor sebagai GeoJSON (EPSG:4326) untuk dimuat ke website.

4

Penyajian WebGIS

Website menampilkan titik lokasi, filter, dan detail rumah makan berdasarkan dataset tersebut.

▤

Sumber data

Data rumah makan akan bersumber dari hasil dari pengumpulan data oleh tim proyek, lalu diolah di QGIS.

⚠

Batasan informasi

  • Jam operasional dan harga dapat berubah sewaktu-waktu dan memerlukan verifikasi langsung sebelum berkunjung.
  • Kelengkapan informasi bergantung pada dataset yang berhasil dikumpulkan.

Informasi bergantung pada dataset yang dikumpulkan dan perlu diverifikasi.
